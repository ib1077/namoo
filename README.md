# 駅IC案内用デジタルサイネージ 3枚版

## 動作

1. 係員案内画像を表示し、ICカード案内を読み上げます。
2. 15秒後、「ICカードの使い方」を7秒表示します（音声なし）。
3. 「ICカードご利用案内」を7秒表示します（音声なし）。
4. 1枚目へ戻り、繰り返します。

タイトル画面の最下部に、小さな「だっだぁー 🐸」入口があります。駅案内とは別モードなので、通常の3枚ループへ混ざりません。

## 公開

フォルダの中身をGitHubリポジトリへアップロードし、GitHub Pagesを有効にしてください。PWA、オフライン保存、Wake LockにはHTTPSが必要です。

- Android Chrome：メニューから「アプリをインストール」
- iPhone Safari：共有ボタンから「ホーム画面に追加」

音声の自動再生制限があるため、起動後の「案内を開始」は1回タップしてください。

## 更新が反映されない場合

PWAの古いキャッシュが残る場合があります。`sw.js` 先頭の `station-signage-v7` の数字を増やし、再度アップロードしてください。
