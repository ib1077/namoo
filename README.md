# 案内サイネージ / おはなし絵本 PWA v2

## 入口
- 案内用サイネージ：内蔵の駅IC案内3画面
- フォルダを選択：book.json / book.txt と画像を入れたフォルダ、または画像だけのフォルダ
- おはなし絵本🐸：内蔵の「だっだぁー」

## 表示時間
- 5秒 / 10秒：その時間を最低表示。読み上げがそれより長い場合は読み上げ終了まで待つ。
- 読み上げ終わるまで：音声ありページは読み上げ終了で次へ。音声なしページは5秒表示。

## フォルダデータ
book.txt は 1行1ページで `画像ファイル名|読み上げ文`。
book.json は `{ "pages": [{"image":"01.jpg","speech":"..."}] }`。
データファイルが無ければ画像をファイル名順で無音表示する。

## iPhone Safari
