# 案内サイネージ / おはなし絵本 PWA v2・21枚収録版

## 収録内容
- おはなし絵本🐸：dadada-01.jpg〜dadada-21.jpg の21枚を番号順に収録。
- 画像は加工せず images/dadada/01.jpg〜21.jpg にコピーしています。
- 表紙はタイトル、偶数番号の本文ページは画像の文字を読み上げます。区切り用の句読点を補っています。
- 絵だけの奇数番号ページ（03〜21）は無音です。
- 案内側の画像・読み上げデータは現行namooのままです。

## 操作
タイトルの「おはなし絵本🐸」で開始します。
画面下の左に前ページ、右に次ページの縮小画像が表示され、タップで移動します。
中央に現在のページ番号 / 21 を表示します。先頭と末尾は循環します。
🏡で読み上げと自動送りを終了し、タイトルに戻ります。

## 表示時間
- 5秒 / 10秒：最低表示時間。読み上げが長ければ終了まで待ちます。
- 読み上げ終わるまで：読み上げ終了で次へ。無音ページは5秒表示します。

## フォルダ読込
book.json は {"pages":[{"image":"01.jpg","speech":"本文"}]} の形式です。
book.txt は1行1ページで「画像ファイル名|読み上げ文」。画像のみなら名前順に無音表示します。

## 配置・更新
ZIPを展開し、ehon_signage_v2_21pages 内のファイルとフォルダを公開先へ配置してください。
元のnamooフォルダとデスクトップの画像は変更していません。
キャッシュ名は ehon-signage-v10。内蔵21枚をインストール時に保存します。
画像やデータを追加・変更した場合は sw.js の CACHE_NAME も更新してください。
HTTPS上で一度オンライン表示してから、開き直してください。
