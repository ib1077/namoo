# おはなし絵本 🐸

混合版 ehon_signage_v2_21pages.zip（キャッシュv10）から分離しました。
このフォルダだけで動きます。別アプリ・npm・共有ライブラリへの依存はありません。

## 収録内容
だっだぁー全21枚。表紙と本文を読み上げ、絵だけのページは無音。

## 操作
ホームの作品・案内を1回タップすると自動再生します。
左右の縮小プレビューをタップして前後に移動し、末尾から先頭へ循環します。
🏡で読み上げを止めてホームへ戻ります。
5秒・10秒は最低表示時間で、読み上げが長い場合は終了まで待ちます。
「読み上げ終了まで」では無音ページを5秒表示します。
Wake Lockは対応端末で利用します。フリック・一時停止は元ZIPに未実装のため今回追加していません。

## GitHub Pagesへの設置
1. このアプリ用のリポジトリを作ります。
2. このフォルダの中身（index.htmlがある階層）をリポジトリ直下へ配置します。
3. Settings → Pagesで公開するブランチと / (root) を指定します。
4. HTTPSの公開URLで開き、内蔵コンテンツを確認します。
5. 必要に応じホーム画面へ追加します。初回はオンラインでキャッシュ保存完了後、オフラインを確認してください。
ファイルを直接ダブルクリックするfile://ではJSON読込やPWAは動作しません。

## 画像・JSON・ホーム項目を追加
1. images/作品名/ に画像を追加します。
2. books/作品名.json を次の形式で作ります。

```json
{"title":"新しいコンテンツ","pages":[{"image":"./images/作品名/01.jpg","speech":"読み上げ文章"},{"image":"./images/作品名/02.jpg","speech":""}]}
```

画像パスはindex.htmlのある階層から指定します。pagesの順が表示順です。
speechが空なら無音です。表示時間はホームの共通設定を使います（durationMsは未対応）。
3. catalog.jsonに {"title":"ホームに表示する名前","data":"./books/作品名.json"} を追加します。
4. 準備中の項目はdata:nullです。JSONと画像を用意してから実際のパスへ変更します。
5. version.js の EHON_VERSION を上げます。一覧に登録したJSONと画像は自動で保存対象になります。

## フォルダから読み込む
下部のボタンでbook.jsonまたはbook.txtと画像があるフォルダを選びます。
book.jsonは上と同形式、画像は選んだフォルダ内のファイル名で指定します。
book.txtは1行ずつ「画像名|読み上げ文」。画像だけならファイル名順で無音表示します。
同名画像の重複を避けてください。外部フォルダは再起動時に再選択します。
端末のフォルダ選択対応に差がありますが、内蔵コンテンツは選択不要です。

## 更新とキャッシュ（ver. 1.1.0）
HOME右上の「更新して再起動」で、更新確認 → 全ファイル取得 → 保存完了確認 → 切替 → 再読み込みを行います。新版は取得後に待機し、ボタン操作まで現在の版で使えます。通信・取得失敗時は現在の版を残し、失敗メッセージを表示します。旧正常版のキャッシュは保持するため更新に伴い保存容量は増えます。

version.js の EHON_VERSION が画面表示・Service Worker・キャッシュ名の共通バージョンです。現在のキャッシュ名は ehon-pwa-1.1.0。コード・画像・JSONを公開するたび、この番号を上げ、公開済み番号を再利用しないでください。アプリフォルダ全体をまとめて配信してください。

初回オンライン起動後、HOMEに「オフラインで使えます」と出たことを確認してから通信を切ります。HTML・JS・CSS・manifest・アイコン・catalog・登録済み作品JSON・全画像を保存します。通常起動はキャッシュ優先で、ナビゲーションのクエリ付きURLも保存済みHTMLへ戻せます。外部CDNへの依存はありません。

旧v1からの初回移行では、オンラインで一度開いて新版の取得を待ち、このアプリのブラウザタブとホーム画面アプリをすべて閉じてから開き直してください。従来v1には更新ボタンがないため、この初回だけは待機中の新版を全画面終了後に有効化します。単なる再読み込みだけでは待機が続く場合があります。新版のHOMEが出た後は「更新して再起動」で更新できます。Chromeの閲覧データ削除は不要です。

利用者データ・localStorage・IndexedDB・駅サイネージのキャッシュは削除しません。現在の絵本アプリは設定の永続保存を行っておらず、再読み込み時は従来どおり表示時間が10秒に戻ります。外部フォルダも従来どおり再選択します。端末の日本語読み上げ音声がオフラインで利用できるかは端末設定にも依存します。

## ファイル管理と今回の確認（2026-10-02）

ホームの表示順は catalog.json の配列順、各作品のページ順は個別JSONの pages の配列順です。ファイル名だけで順番を判断しません。

追加は画像フォルダ → 個別JSON → catalog.json の順で行います。既存項目を残したまま末尾へ追加し、JSONはUTF-8で保存してください。半角英数字の作品名（例 new-story）と、01.jpg、02.jpg の連番を使うと管理しやすくなります。JSONの最後の項目の後にカンマを付けないでください。

変更するファイルの目安：
- 内容・読み上げ・ページ順：books/作品名.json
- 画像：images/作品名/
- ホームの名前・順番・準備中表示：catalog.json
- 見た目：style.css
- 操作や再生処理：app.js
- 配信内容の更新：version.js の EHON_VERSION

未登録のJSONや画像は自動キャッシュされません。画像パスは個別JSONの場所からではなく index.html のある階層から指定します。外部フォルダでは book.json または book.txt を使い、同名画像を避けてください。

初回レビュー時の変更はREADMEのみでした。今回ver. 1.1.0で更新ボタン・共通バージョン・安全更新Service Workerを追加しました。画像とコンテンツJSON、音声再生・ページ送り処理は維持しています。JSON解析、登録された全画像の存在、JavaScript構文を確認しました。画面操作・実音声・オフライン起動の実機確認は未実施です。

実機での確認：入口をタップして初回読み上げ／無音ページ／5秒・10秒で長い音声を最後まで待つ／読み上げ終了モードの無音5秒／前後プレビューで音声取消と移動／ホームで停止／末尾から先頭へループ／画面点灯維持／キャッシュ完了後のオフライン再起動。iPhone SafariとAndroid Chromeでそれぞれ確認してください。

フリック・一時停止・ページ別 durationMs は未実装です。iPhone用 primeSpeechFromUserGesture() は入口の同期タップ処理内に保持してください。
