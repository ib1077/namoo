# 駅IC案内用デジタルサイネージ 3枚版

## 動作

1. 係員案内画像を表示し、ICカード案内を読み上げます。
2. 15秒後、「ICカードの使い方」を7秒表示します（音声なし）。
3. 「ICカードご利用案内」を7秒表示します（音声なし）。
4. 1枚目へ戻り、繰り返します。

タイトル画面の最下部に、小さな「だっだぁー 🐸」入口があります。表紙を含む全21枚を、ことばのページと表情のページを交互に読み進めます。駅案内とは別モードなので、通常の3枚ループへ混ざりません。

再生中は、画面を左へフリックすると次のページ、右へフリックすると前のページへ移動します。画面上には操作案内や矢印を表示しません。

## 公開

フォルダの中身をGitHubリポジトリへアップロードし、GitHub Pagesを有効にしてください。PWA、オフライン保存、Wake LockにはHTTPSが必要です。

- Android Chrome：メニューから「アプリをインストール」
- iPhone Safari：共有ボタンから「ホーム画面に追加」

音声の自動再生制限があるため、起動後の「案内を開始」は1回タップしてください。

## 更新が反映されない場合

PWAの古いキャッシュが残る場合があります。`sw.js` 先頭の `station-signage-v9` の数字を増やし、再度アップロードしてください。
