# おはなしえほん PWA

最初の1タップ後、文章の読み上げ、ページ送り、先頭へのループを自動で行う静的PWAです。

## 絵本の差し替え

1. `images` フォルダへ画像を入れます（例: `01.jpg`、`02.jpg`）。
2. `book.json` の各ページで画像の場所と文章を書き換えます。
3. ページを増減するときは `{ "image": "...", "text": "..." }` の組を増減します。
4. オフラインでも新しい画像を確実に使う場合は、`sw.js` の `APP_SHELL` に画像名を追加し、`CACHE_NAME` の末尾の数字を1つ増やします。

`book.json` がない場合は `book.txt` を読みます。1行を `画像ファイル|読み上げる文章` の形で書いてください。

## GitHub Pagesで公開

このフォルダの中身をリポジトリの公開対象へ置き、GitHub Pagesを有効にします。`file://` で直接開くのではなく、GitHub PagesなどのHTTPS環境で動かしてください。PWA、Service Worker、Wake LockはHTTPS環境が必要です。

## 端末での使い方

- Android Chrome: メニューから「ホーム画面に追加」または「アプリをインストール」。
- iPhone Safari: 共有ボタンから「ホーム画面に追加」。
- 「えほんを はじめる」を1回タップすると読み上げが始まります。

読み上げ音声は端末に入っている日本語音声を使うため、声質は機種によって異なります。iPhoneではバックグラウンド移行や画面消灯後に読み上げが停止することがあります。Wake Lock非対応時も絵本本体は動きます。
