# こっそりだっだぁー：デジタルサイネージ3枚版

## 中身

- 3枚の画像を順番に表示
- 各画像の文章を端末の日本語音声で読み上げ
- 読み上げ終了後に自動で次の画像へ進む
- 3枚目のあと1枚目へ戻って繰り返す
- 対応端末では画面のスリープを抑制
- PWA・オフライン表示対応

## 画像と文章の差し替え

1. `images` フォルダの `01.svg`、`02.svg`、`03.svg` を実際の画像に差し替えます。JPEGの場合は `01.jpg` のような名前でも構いません。
2. `book.json` の `image` を画像名に合わせ、`text` を読み上げたい文章に変更します。
3. `sw.js` の画像名も実際の名前に合わせます。
4. 更新が端末に反映されない場合は、`sw.js` 先頭の `kossori-daddaa-v1` を `kossori-daddaa-v2` に変更します。

## 公開

このフォルダの中身をGitHubリポジトリへ置き、GitHub Pagesを有効にします。PWA・オフライン保存・Wake Lockを使うため、`file://` で直接開くのではなくHTTPSで公開してください。

Android Chromeではメニューから「アプリをインストール」、iPhone Safariでは共有ボタンから「ホーム画面に追加」を選びます。音声の自動再生制限があるため、起動後の「はじめる」だけは1回タップしてください。
